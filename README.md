# Casa Gaviota — Chatbot

Chatbot de atención para Casa Gaviota — Un vuelo sin violencia A.C.

## Instalación

```bash
npm install
```

## Configuración

Crea un archivo `.env` en la raíz con:

```
ADMIN_API_KEY=tu_clave_secreta_aqui
```

## Uso local

```bash
npm run dev
```

Abre `simulator.html` en el navegador para probar el chatbot.
